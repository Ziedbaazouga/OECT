# Transient / Steady-State Measurements

Raw transfer and output-sweep measurement files (`.xls`) used by
`OECT.DataLoader` for the Bisquert and Shirinskaya models.

- `Transfer Measurements.xls`, `Stairs.xls` – steady-state sweeps
- `*vd *vg.xls` – transient pulse-train recordings at each (Vd, Vg) bias point

Select these files via the **Steady:** and **Transient:** browse buttons in
the GUI's Data Loading panel.
